# Amazon Clone 🛒

A **static Amazon homepage clone** built using **HTML and CSS**, deployed using **GitHub Pages**.  
This project focuses on recreating the UI layout of Amazon to strengthen frontend fundamentals.

---

## 🌐 Live Demo

🔗 **Deployed Link:**  
https://uday246r.github.io/Amazon-Clone/

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**

---

## 📂 Project Structure

```

Amazon-Clone/
│
├── index.html     # Main HTML file
├── style.css      # Styling for the page
└── README.md      # Project documentation

````

---

## 🚀 Features

- Amazon-style navigation bar
- Product cards layout
- Header, banner, and footer sections
- Clean UI design
- Beginner-friendly codebase

---

## 📥 How to Run Locally

1. **Clone the repository**
```bash
git clone https://github.com/uday246r/Amazon-Clone.git
````

2. **Navigate to the project**

```bash
cd Amazon-Clone
```

3. **Run the project**

* Open `index.html` directly in your browser
  **OR**
* Use VS Code Live Server extension
